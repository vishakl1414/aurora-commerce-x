Week 2

Day 8


Q1. JPA Entity kya hota hai?

Ek Java class jo database table se directly connect hoti hai — @Entity annotation lagate hain


Q2. @Entity annotation kya karta hai?

Spring Boot ko batata hai ki ye class ek database table hai


Q3. @Table(name = "products") ka kya kaam hai?

Database mein table ka naam set karta hai


Q4. @Id annotation kya karta hai?

Ye field primary key hai — ye batata hai


Q5. @GeneratedValue(strategy = GenerationType.IDENTITY) ka kya matlab hai?

ID automatically database mein generate hogi — manually deni nahi padegi


Q6. int id ko Long id kyun kiya?

Database ke liye Long better hota hai — zyada numbers store kar sakta hai


Q7. JPA ke liye default constructor kyun zaroori hota hai?

JPA objects create karta hai internally — default constructor ke bina error aata hai


Q8. Console mein ye line kyun aayi — Hibernate: create table products...?

spring.jpa.hibernate.ddl-auto=update set tha — isliye JPA ne automatically table bana diya


Q9. Humne koi SQL likha table banane ke liye?

Nahi — JPA ne khud automatically products table bana diya


Q10. @GeneratedValue ke bina kya hota?

ID manually deni padti har product ke liye — automatically generate nahi hoti
